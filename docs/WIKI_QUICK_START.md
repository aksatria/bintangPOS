# Quick Start (30 Menit)

## Tujuan

Membantu user baru mulai pakai sistem dengan aman dalam waktu singkat.

## Langkah Cepat

1. Login dan pastikan cabang aktif benar.
2. Buka `Dashboard` untuk cek kondisi umum.
3. Jalankan 1 transaksi POS sederhana.
4. Buat 1 draft pembelian supplier.
5. Ajukan 1 approval pembelian.
6. Approve/reject dari `Approval Center` (oleh owner/approver).
7. Cek hasil di `Jurnal Umum` dan `Laporan Akuntansi`.

## Checklist Berhasil

- POS transaksi tersimpan.
- Draft pembelian tersimpan.
- Approval berubah status.
- Jurnal otomatis muncul.
- Laporan bisa dibuka tanpa error.
