# Modul Approval Center

## Fungsi

- Pusat persetujuan lintas modul.
- Approve/reject dengan catatan.
- Monitoring SLA approval.

## Alur Ringkas

1. User operasional mengajukan request.
2. Request masuk ke daftar approval.
3. Owner/approver proses approve/reject.
4. Sistem simpan riwayat keputusan.

## Praktik Baik

- Wajib isi alasan saat reject.
- Review nominal/dampak sebelum approve.
