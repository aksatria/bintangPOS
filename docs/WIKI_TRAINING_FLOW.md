# Training Flow Cepat (1 Hari)

Target: tim bisa operasional Supplier + Approval + Akuntansi dasar dalam 1 hari training.

## Sesi 1 - Kasir (60 menit)

1. Login dan cek cabang aktif.
2. Simulasi transaksi POS normal.
3. Simulasi split payment.
4. Validasi transaksi masuk riwayat.

Output:
- Checklist step kasir lengkap.

## Sesi 2 - Admin Supplier (120 menit)

1. Buat/cek supplier.
2. Buat draft pembelian (multi item).
3. Edit draft.
4. Ajukan approval.
5. Setelah disetujui, receive barang.
6. Catat pembayaran.
7. Verifikasi status hutang.

Output:
- 1 dokumen pembelian end-to-end sampai status ter-update.

## Sesi 3 - Owner Approval (60 menit)

1. Buka daftar approval.
2. Review detail approval pembelian supplier.
3. Approve/reject + isi catatan.
4. Verifikasi perubahan status.

Output:
- Riwayat approval tercatat.

## Sesi 4 - Akuntansi Dasar (90 menit)

1. Buka Laporan Akuntansi (set filter tanggal).
2. Buka Jurnal Umum, cek jurnal dari transaksi uji.
3. Buka Buku Besar, filter per akun.
4. Cocokkan angka ringkas (debit-kredit) pada periode uji.

Output:
- Validasi jurnal otomatis terbukti dari transaksi latihan.

## Closing Checklist Trainer

1. Semua role menyelesaikan SOP masing-masing.
2. Checklist training terisi lengkap.
3. Tidak ada error blocking.
4. Tim paham status utama: approval, barang, bayar.
