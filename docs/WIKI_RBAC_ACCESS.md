# RBAC & Akses

## Tujuan

Menjamin setiap user hanya mengakses fitur sesuai tanggung jawabnya.

## Prinsip Utama

1. Role-based access (`kasir`, `admin`, `owner`, dst).
2. Permission granular per modul.
3. Scope data mengikuti cabang aktif.

## Praktik Baik

1. Hindari berbagi akun.
2. Review akses user secara berkala.
3. Cabut akses user yang sudah tidak aktif.
